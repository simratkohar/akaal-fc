# Akaal FC

App d'équipe d'Akaal FC : calendrier, présences, compo, scores, stats, votes, paiements (foot à 7, 8 et 11).
100 % gratuite : GitHub Pages + Firebase (offre Spark).

- Lien de l'app (une fois GitHub Pages activé) : https://simratkohar.github.io/akaal-fc/
- Sans configuration Firebase, l'app tourne en **mode démo** (données fictives sur le téléphone).
