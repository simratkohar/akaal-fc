# Skills HyperFrames

Les dossiers `hyperframes/`, `hyperframes-cli/` et `media-use/` sont copiés tels quels du paquet npm
[`hyperframes`](https://www.npmjs.com/package/hyperframes) **v0.9.9** (HeyGen, https://github.com/heygen-com/hyperframes),
sous licence **Apache-2.0**. Ils donnent à Claude Code les règles et bonnes pratiques pour créer des vidéos
en motion design (HTML → MP4).

Mettre à jour : `npx hyperframes@latest skills update`, ou recopier `dist/skills/*` d'une version plus récente du paquet.
